# Context Map

## Contexts

- tw-scanner (`packages/tw-scanner`) — AST-based Tailwind v4 class validator: extraction, validation, and reporting
- agent-gate (`packages/agent-gate`) — runs FCIS architecture rules and project checks from AI agent hooks (Claude Code, kiro-cli)

A context's glossary lives at `packages/<name>/CONTEXT.md`. It is created lazily, when terms get resolved (see `docs/agents/domain.md`), so none exist yet.

## Relationships

No cross-context relationships yet — the two packages are independent.
